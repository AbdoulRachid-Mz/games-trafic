1️⃣ CRÉATION D’UN TOURNOI
📌 Logique métier

Un tournoi est une entité permanente.
Les prix et frais d’inscription appartiennent aux éditions, pas au tournoi.

✅ Formulaire de création (minimal et propre)

Supprimer tout ce qui concerne :

❌ prizePool

❌ entryFee

Garder uniquement :

🏷 Identité

name

slug

description

shortDescription

profileImage

coverImage

🎮 Configuration jeu

game

platform

gameMode (1v1, 5v5, etc.)

allowedTeams

👥 Configuration participants

minParticipants

maxParticipantsPerEdition

🌍 Visibilité

visibility

inviteOnly

requiresAccessCode

📞 Contact

contactEmail

contactPhone

discordServer

whatsappGroup

7️⃣ MATCHES

Les matches sont la source de vérité.

Ils doivent :

Être générés automatiquement selon format

Être liés :

editionId

phaseId

groupId (si applicable)

bracketNodeId (si applicable)

📌 Round Robin

Chaque participant rencontre tous les autres :

Formule :

n(n-1)/2


Ou x2 si aller-retour

📌 Elimination

Matches générés par round :

Round 1 → 8 matches
Round 2 → 4 matches
Semi → 2
Final → 1
