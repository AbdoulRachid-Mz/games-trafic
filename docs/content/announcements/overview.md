# Alertes Officielles: Annonces

## 🧩 Vue d’ensemble
Au lieu de polluer les notifications avec des publicités internes, les éléments généraux utilisent des <beautifulMention>Annonces</beautifulMention> (Bannières d'alerte, popups modales occasionnels).

## ⚙️ Fonctionnement
Les créateurs ou modérateurs écrivent les annonces dans la base de données. 
On distingue deux catégories :
1. **Annonce Globale** : Maintenance d'un serveur, arrivée de la nouvelle Saison avec une récompense importante.
2. **Annonce de Tournoi / Édition** : L'organisateur communique directement avec tous les joueurs de CE tournoi uniquement sur un changement de règle de dernière minute.

## 👤 Côté utilisateur
Présence en haut de l'écran visible par tous. Si des urgences sont de mise, on emploie les composants Alert du kit UI local.
